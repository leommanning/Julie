# Julie Driving Tuition Website

A modern, responsive single-page website for Julie Driving Tuition, a DVSA approved driving instructor serving Frinton-on-Sea, Walton-on-the-Naze, Clacton-on-Sea and surrounding areas.

## 🚗 Features

- **Responsive Design** - Optimized for desktop, tablet, and mobile devices
- **Custom Cursor** - Interactive car-themed cursor for desktop users
- **Smooth Animations** - Intersection Observer-based reveal animations
- **Mobile Menu** - Hamburger menu for smaller screens
- **Contact Methods** - Multiple contact options including phone, SMS, and WhatsApp
- **Enquiry Form** - Client-side form that opens SMS/email with pre-filled message
- **Accessibility** - Skip links, ARIA labels, semantic HTML, and reduced motion support
- **Performance** - Optimized images, minimal dependencies, and efficient CSS

## 📋 Prerequisites

No build tools or dependencies required! This is a pure HTML/CSS/JavaScript website.
